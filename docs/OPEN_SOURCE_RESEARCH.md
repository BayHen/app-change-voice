# Open-source integration research

The upstream repositories were inspected as references. Current stable tags and exact maintenance dates were not independently confirmed unless noted. Benchmark claims below are evaluation criteria for VoiceMorph rather than upstream performance results.

| Upstream                                                                       | Architecture and license evidence                                                                                                                               | Decision and integration boundary                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Mask](https://github.com/guilhermeeng99/mask)                                 | Windows Tauri 2/Rust/React app with Bun, DSP, soundboard and local RVC/ONNX. MIT code. Weight provenance needs separate review.                                 | Architectural Reference. Compare lifecycle and hardware test organization with audio/stream.rs and TEST_PLAN.md. No dependency. Avoid a second engine. Recheck asset terms before reuse.                                                                                           |
| [Virtual Audio Driver](https://github.com/VirtualDrivers/Virtual-Audio-Driver) | Windows 10/11 WDK driver derived from SysVAD. MIT original code and MS-PL samples per upstream notices. Upstream describes active maintenance.                  | Optional Integration. Test independently installed, trusted signed package with routing/windows.rs and documented endpoint pairing. No crate. Require clean install, capture, multiclient, recovery and redistribution review before any bundling. Existing cable is the baseline. |
| [FunDSP](https://github.com/SamiPerttu/fundsp)                                 | Rust composable DSP graphs. README shows 0.23.0 and optional FFT/file features. Confirm manifest license at selected revision.                                  | Optional Integration. Compare one missing processor with effects/chain.rs and plugins/factory.rs. Use a narrow adapter and minimal features if accepted. Verify frequency response, allocations and CPU. Existing EQ remains the baseline.                                         |
| [DeepFilterNet](https://github.com/Rikorose/DeepFilterNet)                     | Rust/Python full-band speech enhancement. Upstream covers repository code and weights under MIT or Apache-2.0. Verify separate external assets.                 | Optional Integration after baseline. Try a separate benchmark against audio/noise.rs using the same lawful recordings, RMS, intelligibility, CPU and delay. Gate Windows build and model packaging. Retain RNNoise as default until measurements justify change.                   |
| [Rodio](https://github.com/RustAudio/rodio)                                    | Rust playback library, MIT or Apache-2.0. Evaluate chosen CPAL and decode feature versions before use.                                                          | Unsuitable as replacement for the existing shared sink. A second playback path would complicate timing, mixing and device ownership. Keep Hound WAV and the existing mixer. Reassess decode-only dependencies if formats become a requirement.                                     |
| [Tauri plugins](https://github.com/tauri-apps/plugins-workspace)               | Official cross-platform plugin workspace with per-plugin support and release versions. MIT or Apache-2.0.                                                       | Direct Integration, already used. Keep dialog, updater, process and shortcut plugins. Check capabilities, versions and signed upgrade in lib.rs and workflows. Add a plugin only for a specific unmet requirement.                                                                 |
| [wavesurfer.js](https://github.com/katspaugh/wavesurfer.js)                    | Browser waveform player, TypeScript and Web Audio, BSD-3-Clause. Verify selected version in WebView2.                                                           | Optional Integration for recordings only. Prefer precomputed peaks with existing playback clock in RecordingPanel.tsx. Compare native rendering first. Measure long-file memory and avoid duplicate playback or raw live PCM IPC.                                                  |
| [w-okada Voice Changer](https://github.com/w-okada/voice-changer)              | Realtime model-based client/server deployment. Upstream lists multiple licenses and model-specific voice terms. GPU and runtime support depend on distribution. | Architectural Reference for optional worker isolation, model management and telemetry in ai/. No app/backend dependency. A future offline experiment requires trusted weights, explicit consent, resource budgets and DSP fallback.                                                |

Before adding a dependency, record release tag, commit, recent maintenance and advisories, exact Windows build requirements, transitive notices, and the A/B evidence supporting adoption.

# Thiết lập OBS Studio

1. Start audio processing và virtual routing trong VoiceMorph.
2. OBS → Sources → Add → Audio Input Capture.
3. Chọn `CABLE Output (VB-Audio Virtual Cable)`.
4. Theo dõi OBS meter và record một đoạn ngắn khi đổi Natural/Radio preset.

Không thêm cùng endpoint ở cả Global Audio Devices và Sources nếu muốn tránh double audio.
